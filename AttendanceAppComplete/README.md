# AttendanceApp

اپلیکیشن شخصی حضور و غیاب اندروید بر پایه Kotlin + Jetpack Compose + Room.

## ویژگی‌ها
- Android 9 (API 28) و بالاتر
- ثبت ورود و خروج با ساعت واقعی دستگاه
- انتخاب شیفت A/B/C
- تقویم شمسی داخلی
- اتصال اینترنتی برای دریافت تعطیلات سال
- گزارش ماهانه: حضور، اضافه‌کار، کسرکار، تأخیر، تعجیل، مبلغ اضافه‌کار، مرخصی و آف
- ویرایش و حذف رکوردها
- پروفایل و نرخ اضافه‌کار ستادی
- بخش درباره برنامه با متن «برنامه نویس: M.R»

## اجرای پروژه
Android Studio Quail 4 یا جدیدتر، JDK 17.
Project را باز کنید و Gradle Sync را بزنید. برای Build اینترنت لازم است تا وابستگی‌ها دریافت شوند.

منبع تقویم اینترنتی انتخاب‌شده در این نسخه:
https://persian-calendar-api.sajjadth.workers.dev/

این سرویس طبق مستندات خودش پارامتر year را به صورت سال جلالی می‌پذیرد و از 1300 تا 1500 را پوشش می‌دهد.
