# ساخت APK با GitHub Actions

1. محتویات این پوشه را داخل یک Repository در GitHub قرار بده.
2. در GitHub وارد تب **Actions** شو.
3. Workflow با نام **Build Android APK** را انتخاب کن.
4. روی **Run workflow** بزن یا یک Commit جدید انجام بده.
5. بعد از سبز شدن Build، وارد همان اجرای Workflow شو.
6. پایین صفحه در بخش **Artifacts** فایل `AttendanceApp-debug-apk` را دانلود کن.
7. فایل APK داخل ZIP دانلودی را روی گوشی نصب کن.

این Workflow به Android Studio روی کامپیوتر نیاز ندارد.
